# Super Mario Game (x86 Assembly / MASM615)

A recreation of the classic Super Mario Bros game developed in x86 Assembly language using the Irvine library in MASM615.
This project was built as part of a COAL (Computer Organization and Assembly Language) course.

---

## Features

* Player movement and jumping mechanics
* Enemy interactions
* Multiple levels (Grassland, Underground, Sky, Castle)
* Score and HUD system
* Sound effects using Irvine library
* Roll-number-based customization (as per project requirements)

---

## Technologies Used

* x86 Assembly Language
* MASM615
* Irvine Library

---

## How to Run

1. Install MASM615
2. Ensure Irvine library is properly configured
3. Open the `.asm` file in MASM615
4. Assemble and run the program

---

## Controls

* Arrow keys → Movement

---

## Project Structure

* `.asm` → Main game source code
* `resources/` → Assets
